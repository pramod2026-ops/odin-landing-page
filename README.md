# PG Studio

A static business website for PG Studio, positioned as an independent web design and development studio for small businesses and independent professionals.

## Pages

- `index.html` introduces the studio, services, and project process.
- `contact.html` collects project details and prepares an email inquiry.
- `style.css` contains the responsive layout and shared visual styles.

## Preview

Open `index.html` in a browser, or serve the project directory with any static file server. No build step or JavaScript dependencies are required.

## Contact form setup

The form validates its fields and opens the visitor’s default email app addressed to the studio inbox, with the project details filled in. It does not send data to a server, so the visitor must send the prepared email from their mail app.

## Technology

HTML, CSS, and a small inline script for the contact form and current copyright year. Roboto is loaded from Google Fonts.
